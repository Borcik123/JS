1. W jaki sposób można określić właściwość danego obiektu (dwa sposoby wraz z przykładami)?

Właściwość obiektu można określić na dwa sposoby:

Sposób 1 – notacja kropkowa:

nazwa_obiektu.nazwa_właściwości = "tekst";
np. auto.marka = "Opel Omega";

nazwa_obiektu.nazwa_właściwości = liczba;
np. auto.rok = 1996;
auto.cena = 25000;

Sposób 2 – notacja tablicowa:

nazwa_obiektu["nazwa_właściwości"] = wartość;
np. auto["cena"] = 25000;

2. W jaki sposób można odwołać się do pól (właściwości) i metod?

Do właściwości i metod obiektu odwołujemy się, podając nazwę obiektu i kropkę, a następnie nazwę pola lub metody.

Przykład:
console.log(samochod1.kolor); // wyświetla kolor obiektu

3. Wymień cechy charakterystyczne konstruktora

  • Jest wywoływany automatycznie przy tworzeniu obiektu.
  • Nosi taką samą nazwę jak funkcja (klasa w JS).
  • Nie zwraca żadnej wartości.
  • Może przyjmować argumenty do inicjalizacji pól obiektu.
  • Obiekt tworzony jest za pomocą słowa kluczowego new.

4. Konstruowanie obiektu – przykład (3 pola i 1 metoda)

Przykład obiektu:

var osoba_1 = {
    nazwisko: 'Kowalski',
    imie: 'Jan',
    zawod: 'piekarz',
    wyswietl: function() {
        document.write(this.nazwisko + ' ' + this.imie);
    }
};

5. Znaczenie słowa this. Jak oddzielamy pola oraz metody?

Uwaga 1:
Słowo kluczowe this pozwala odwołać się do pola lub metody obiektu z wnętrza tego obiektu.

Uwaga 2:
Pola i metody w obiekcie oddzielamy przecinkami.

6. Konstruktor w JS na podstawie przykładu

W JS zamiast klas stosuje się funkcje, które pełnią rolę konstruktora.

Przykład:

function klient(nazwisko_k, imie_k, zawod_k) {
    this.nazwisko = nazwisko_k;
    this.imie = imie_k;
    this.zawod = zawod_k;
    this.wypisz = function() {
        alert(this.nazwisko + ' ' + this.imie);
    }
}

Słowo this odnosi się do aktualnie tworzonego obiektu.

7. Znaczenie słowa kluczowego new wraz z przykładem

Słowo kluczowe new służy do tworzenia nowego obiektu na podstawie konstruktora.

Przykład:

var osoba1 = new klient('Kowalski', 'Jan', 'kierowca');
var osoba2 = new klient('Nowak', 'Anna', 'sekretarka');

Powstały dwa obiekty: osoba1 i osoba2.

8. Znaczenie słowa kluczowego prototype wraz z przykładem

Właściwość prototype pozwala dodawać wspólne metody i właściwości dla wszystkich obiektów tworzonych z danego konstruktora.

Przykład:

function klient() {
    this.nazwisko = 'Bielski';
    this.imie = 'Paweł';
}

klient.prototype.pisz_dane = function() {
    document.write(this.nazwisko + ' ' + this.imie);
};

klient.prototype.zawod = 'kierowca';

var osoba1 = new klient();
osoba1.pisz_dane();

Opis: Po użyciu prototype każdy nowo tworzony obiekt konstruktora klient posiada dodatkową metodę i właściwość.
